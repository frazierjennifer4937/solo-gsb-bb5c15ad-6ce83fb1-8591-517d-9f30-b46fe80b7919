# 访谈稿匿名化映射编辑器

在浏览器中编辑访谈稿的匿名化规则：自动按“称呼”命中替换为统一代号，支持鼠标框选指派，并可将个别称呼命中标记为“保留原文”例外。

## 启动

```bash
docker compose up --build
```

启动后在浏览器访问 **http://localhost:3000**（容器端口固定为 **3000**）。

不使用 Docker 时也可直接运行：

```bash
npm install
npm start
# 访问 http://localhost:3000
```

## 操作说明

1. **加载原稿**：首页粘贴访谈原稿后点击“加载原稿，开始匿名化”，或点击顶部“加载内置示例”快速体验。
2. **添加人物**：在右侧“人物规则”中填写统一代号（如：受访者A）与称呼（多个用逗号分隔），添加后原稿中的称呼会自动匿名化；同一位置存在多个称呼命中时，最长称呼优先。
3. **显式框选（优先级最高）**：在原稿中用鼠标框选任意片段，在弹窗中指派给已有或新建人物。框选占据其字符区间，与之重叠的称呼命中及保留原文例外均会让位。
4. **保留原文例外**：在“字符区间映射表”中，对任意“称呼命中”一行点击“保留原文”。例外按原稿字符区间记录：
   - 例外区间内的原文不做替换，直接进入预览；
   - 与例外区间重叠的所有自动称呼命中被屏蔽；
   - 显式框选仍可覆盖例外（含部分覆盖，未覆盖部分继续保留原文）。
5. **例外列表**：页面底部“保留原文例外”列出每条例外的**原片段、来源人物与原稿区间**，点击可在原稿/预览间双向定位；点击“恢复匿名”可删除该例外，被屏蔽的称呼命中重新生效。
6. **撤销**：添加人物、框选、标记例外、恢复匿名、删除人物均计入同一个撤销栈，点击顶部“撤销最近规则”可逐步回退（撤销删除人物时会连带恢复其框选与例外）。
7. **双向高亮**：点击或悬停原稿/预览中的高亮片段（以及映射表行、例外条目），两侧对应位置联动高亮。
8. **复制结果**：点击“复制匿名预览”复制预览文本；“重新粘贴原稿”会清空全部规则重新开始。
